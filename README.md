This repository contains the graduation project proposal for an integrated Geomatics framework designed to support post-conflict urban recovery and infrastructure management.

The proposed framework combines Remote Sensing, GIS, Machine Learning, spatial databases, and BIM-GIS integration to support urban damage assessment, infrastructure documentation, and subsurface utility management.

Project Objectives

- Assess visible urban damage using multi-temporal remote sensing data.
- Apply machine learning methods for urban feature classification.
- Develop a spatial database for infrastructure and subsurface utility information.
- Identify and document gaps in underground infrastructure data.
- Integrate geospatial infrastructure data with 3D BIM models.
- Establish a foundation for a digital twin of post-conflict urban infrastructure.

Methodology

1. Remote Sensing

Multi-temporal satellite imagery is used to identify and assess visible changes in the urban environment.

2. Machine Learning

Machine learning techniques, including Random Forest and Support Vector Machine (SVM), are proposed for urban feature classification and damage assessment.

3. Spatial Database

Infrastructure and subsurface utility information will be organized within a structured spatial database, with data gaps documented where information is unavailable.

4. BIM-GIS Integration

Geospatial infrastructure data will be integrated with 3D BIM models to support visualization, analysis, and infrastructure management.
