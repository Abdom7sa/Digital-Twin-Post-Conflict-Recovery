# Digital Twin Framework for Post-Conflict Urban Recovery & Subsurface Utility Management

## 📌 Overview
This repository contains the graduation project proposal for an integrated Geomatics framework. The project addresses urban damage assessment and subsurface utility management in post-conflict environments using Remote Sensing, GIS, Machine Learning, and BIM-GIS integration.

## 📄 Documentation
* **Full Proposal:** You can view or download the complete PDF document directly [here](./Project_Proposal.pdf).

## 🔑 Key Methodology Components
- **Multi-Temporal Remote Sensing:** Identifying visible structural damage using satellite imagery.
- **Machine Learning (ML):** Applying Random Forest & SVM for urban feature classification.
- **Subsurface Utility Spatial DB:** Mapping underground infrastructure and documenting data gaps.
- **BIM-GIS Integration:** Connecting spatial infrastructure data with 3D BIM models.

## 🛠️ Tools & Tech Stack
- **GIS:** ArcGIS Pro, QGIS
- **Database:** PostGIS / GeoPackage
- **Data Science:** Python (GeoPandas, Scikit-Learn)
- **BIM:** Autodesk Revit / Civil 3D
