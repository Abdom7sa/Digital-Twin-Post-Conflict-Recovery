Digital Twin Framework for Post-Conflict Urban Recovery & Subsurface Utility Management

A graduation project proposal for an integrated Geomatics framework supporting post-conflict urban recovery, infrastructure assessment, and subsurface utility management through the integration of Remote Sensing, GIS, Machine Learning, and BIM-GIS.

🔑 Methodology

- Remote Sensing — Multi-temporal satellite imagery for urban damage assessment.
- Machine Learning — Random Forest and SVM for urban feature classification.
- Spatial Database — Structured management of infrastructure data and identified data gaps.
- Subsurface Utilities — Spatial representation and management of underground infrastructure.
- BIM-GIS Integration — Linking geospatial infrastructure data with 3D BIM models.
